    Structlnk · 直接绘图

    0.7.0 · Claude 接口、按需修改批准、图片识别与可编辑化学绘图。

    1. 使用画布左侧的键、环、文字和箭头工具直接绘图，无需双击进入另一个编辑器，也无需点击「放入画布」。
    2. 顶部「Agent」读取当前 KET/SMILES，也可识别上传的化学图片；只有模型提出画布修改时才请求批准，点击「批准并应用」后才改变画布。
    3. Agent 支持 OpenAI、Claude、DeepSeek 与其他兼容接口。密钥由系统加密保存，不进入项目文件。
    4. 箭头工具展开菜单包含反应、平衡和弯箭头；元素面板支持金属原子，配位键使用键工具中的相应类型。
    5. 选择工具可框选、移动和修改内容；原生工具提示主要为英文。
    6. 将交替双键六元环模板点在已有普通碳原子上时，会自动修正共用碳的键级并保持碳标记隐藏。
    7. Ctrl+S 保存整个画布，包含刚刚画出的结构。编辑后自动保存恢复副本。
    8. 顶部「打开」支持旧版 Structlnk 项目和 ChemDraw CDX / CDXML；导入后直接编辑。
    9. ACS 样式设置化学绘图参数和导出比例。画布是可平移缩放的工作区，导出页尺寸见样式说明。

    Agent 输出可能存在化学错误，批准前应检查摘要，应用后应核对价态、立体化学、配位键方向和机理箭头。原有撤销可以恢复应用前画布。

    第三方许可

    

    画布 Agent · API 设置
    发送消息时，当前画布的 KET/SMILES、你的指令及所附图片会发送到这里配置的 API。请求由本机主进程直接发出；密钥使用 Windows 系统加密保存，不写入项目文件。
    

    ACS 1996 兼容样式
    Structlnk 根据公开的 ACS 1996 参数独立实现此兼容样式。切换样式会设置当前画布的默认绘图参数及导出比例；Ctrl+Z 可撤销。
    默认标准键长14.4 pt / 5.08 mm
    普通键线宽0.6 pt
    楔形键宽度2.0 pt
    多重键间距键长的 18%
    虚线楔形键间距参数2.5 pt
    原子标签 / 新增文字Arial，10 pt，黑色
    页面绘图区540 × 720 pt
    PDFUS Letter 纵向，四边 36 pt，100%
    PNG透明背景，600 dpi，4500 × 6000 像素
    画布可以平移与缩放。使用选择工具可单独拖动原子，手动调整局部键长和键角并拉开拥挤结构；拖动后的坐标会保存到项目并用于导出，不会被样式自动复位。画布视觉缩放不改变导出比例。
    这是根据公开参数独立实现的兼容样式，没有复制 ChemDraw 的样式文件、模板、图标或代码。标签避让、1.6 pt 标签留白及部分特殊粗键的外观仍由当前化学引擎处理；调整原子后请检查排版和箭头端点。
    参数参考来源为 ChemDraw 官方公开的“ACS Document 1996”文档；该名称仅用于说明参数来源。
